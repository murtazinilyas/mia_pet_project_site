# 🖥️ ПК-Мастер — сайт услуг по ремонту и настройке ПК (г. Бугульма)

Статичный сайт с формой заявки. Данные формы через собственный Python-сервер создают лид в CRM **Битрикс24**.

## Структура проекта

```
├── site/              — статичный сайт
│   ├── index.html     — главная страница
│   ├── services.html  — перечень услуг
│   ├── request.html   — форма заявки
│   ├── consent.html   — согласие на обработку персональных данных
│   ├── css/style.css  — стили
│   └── js/main.js     — логика формы, валидация, отправка на /api/request
├── bot/               — бэкенд
│   ├── server.py      — сервер + эндпоинт /api/request (создание лида в Битрикс24)
│   ├── config.env     — настройки вебхука Битрикс24 (заполнить!)
│   └── README.md      — эта инструкция
└── infrastructure/    — вспомогательные материалы (опционально)
```

## Как запустить

Сервер работает из WSL (проект находится в `\\wsl.localhost\...`).

```bash
cd /home/van/site/bot
python3 server.py
```

Откройте в браузере: **http://localhost:8080**

Сервер раздаёт файлы сайта из папки `../site` автоматически. По умолчанию используется порт `8080`.
Сменить порт можно переменной окружения:

```bash
PORT=9000 python3 server.py
```

## Как подключить Битрикс24

1. В Битрикс24 откройте: **Приложения → Вебхуки → Входящие вебхуки → Добавить**.
2. В правах доступа отметьте **crm** (например, `crm.lead`).
3. Скопируйте адрес вебхука вида:
   `https://ВАШ_ПОРТАЛ.bitrix24.ru/rest/<user_id>/<webhook_token>/`
4. Откройте файл [`config.env`](config.env) и впишите значение:

```env
BITRIX_WEBHOOK_URL=https://ВАШ_ПОРТАЛ.bitrix24.ru/rest/1/ВАШ_ТОКЕН/
LOG_FILE=../logs/app.log
```

5. Перезапустите сервер (`Ctrl+C`, затем снова `python3 server.py`).
   При запуске появится строка **«Битрикс24: настроен (создание лидов активно)»**.

## Как это работает

1. Клиент заполняет форму на странице [`../site/request.html`](../site/request.html).
2. [`../site/js/main.js`](../site/js/main.js) отправляет POST
   `{ name, phone, city, service, address, call_time, call_first, message }` на `/api/request`.
3. [`server.py`](server.py) принимает запрос и вызывает метод **`crm.lead.add`** вебхука Битрикс24,
   создавая лид с полями:
   - **TITLE** — «Заявка с сайта — <услуга>»;
   - **NAME** — имя клиента;
   - **PHONE** — телефон (тип WORK);
   - **CITY**, **ADDRESS** — город и адрес;
   - **SOURCE_ID = WEBFORM** — источник «Форма на сайте»;
   - **COMMENTS** — услуга, удобное время звонка, предварительный звонок, описание.

> Пока `BITRIX_WEBHOOK_URL` не заполнен, сервер не создаёт лиды,
> а просто выводит содержимое заявки в консоль — так удобно проверить работу формы без настройки CRM.

## Логирование

Все события сервера (старт, запросы, результаты создания лидов) дублируются в файл логов.
Путь задаётся переменной `LOG_FILE` в [`config.env`](config.env):
- относительно папки `bot/` (например `logs/app.log`) или абсолютный путь (`/var/log/pc-master/app.log`);
- если оставить пустым — логи пишутся только в консоль.

Файл и каталог создаются автоматически при первом запуске.

## Полезно знать

- Токен вебхука **не должен** попадать в клиентский код (`site/js/`) — он хранится только на сервере в `config.env`.
- Если нужно расширить состав лида (свои поля), добавьте их в словарь `fields` в функции `create_bitrix_lead()` в [`server.py`](server.py).
- Для публикации в интернет сервер нужно запускать на хостинге/VPS, а не на локальной машине.
